# MITF Wallet — by Masarat {: .wallet-lead }

**[Masarat](https://masarat.ly/)** builds financial infrastructure for banks and regulated partners. **MITF Wallet** is the platform for **digital wallets**: onboarding, balances, P2P and merchant payments, cash-out, and treasury flows — anchored in a **single ledger** so finance, partners, and auditors share one source of truth.
